# 译文追踪资料

这里保存各轮整理的界面译文、CLI 帮助和使用提示。实际构建以 `version.json` 指定的源码补丁为准；仅修改词表不会改变程序。

词表不能当作全局替换规则。`active`、`error`、`submit`、`leader` 等词可能同时出现在界面和内部标识中：可见按钮可以翻译，参数解析、键位查找、协议数据和保存的配置必须使用上游标识。相同英文短语也可能因显示场景不同而使用不同中文。

新增翻译时，请定位 Rust 中最终显示文字的位置，同步修改源码与对应词表，检查占位符、显示列宽、链接与复制内容，再运行契约检查和相关回归测试。历史词表用于追踪，不表示每个条目在所有场景都应替换。
