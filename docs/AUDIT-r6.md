# r6 本地化影响与回归检查

本轮基于固定上游 `0.169.0` 检查中文显示、搜索兼容性、终端宽度和程序标识。它不是“全界面已翻译”或“没有任何 bug”的证明。可重复的测试结果和扫描统计见 [verification.json](verification.json)。

## 已修复的问题

| 问题 | 原因及影响 | r6 处理 |
| --- | --- | --- |
| `/config` 用 `notify when` 搜不到原来的设置 | 中文名称替换后，旧的英文名称没有全部进入搜索别名 | 为 20 项设置保留英文分组与名称别名，中文显示不变；原有英文搜索用例恢复通过 |
| `/keymap` 用 `Open Transcript` 搜索不稳定 | 搜索按子串匹配，`open_transcript` 与含空格的英文名称不同 | 同时支持中文、英文空格写法和完整 `global.open_transcript` 标识，并验证选择事件一致 |
| 快捷键中文说明可能对应错误场景 | `move_up` 等操作在编辑器、列表和 Vim 中重名；仅按操作名找译文会取错说明 | 改为同时匹配场景和操作；验证列表操作仍发送 `list.move_up` |
| 后台任务退出摘要仍显示英文 `Token usage:` | 旧汉化误改了用于匹配上游输出的字符串，替换没有命中 | 保留英文匹配键，在显示边界翻译；区分“目前的 token 用量”和已结束摘要 |
| 设置面板中文值挤占说明列 | 固定宽度格式化按字符数填充，终端按显示列计算宽度 | 按 Unicode 显示宽度补空格，保留原来的设置值与保存逻辑 |

退出摘要继续使用上游的数值格式化及计数。上游 `total` 的混合计数扣除了缓存输入，因此中文写作“非缓存合计”，并单列输入、缓存、输出和推理信息。它不是账单金额。测试同时核对运行中、停止后和嵌入模式下的数值。

本轮还补齐警告计数、任务仍在运行时的退出选择、会话被其他应用占用的提示、创建分支进度，以及相关快捷键说明；调整了用量图表中消息数量的中文表达。

## 防止误改功能的检查

`tools/contracts.rs` 使用 Rust 语法树提取模式匹配、解析键、序列化属性、JSON 字段和部分字符串操作。`tools/verify-contracts.mjs` 将修改后的生产代码与固定上游逐项比较。显示适配器中的必要差异采用精确的前后值清单，新增或过期差异都会使检查失败。

另行比较了 171 个快捷键的场景、操作标识和功能门槛、斜杠命令枚举及分发逻辑、状态栏与标题配置的序列化值，以及 44 条提示中的命令、网址和快捷键占位符。

这是面向高风险字符串的回归检查，不是通用的程序等价性证明。它不覆盖所有宏展开、运行时服务端响应或模型生成内容。功能仍需要相应的行为测试；例外清单中的每项变化都需要人工解释。

## 仍需要继续处理的内容

- `codex-zh --help`、子命令帮助和框架自动生成的标题。
- 实际启动时仍可出现英文的桌面应用推广提示，以及禁用菜单项的 `(disabled)` 后缀；本轮已确认并记录，尚未替换。
- 登录引导、诊断、低频连接与恢复流程中的英文说明。
- 部分线程占用错误、暂停审查提示等较少出现的路径。
- 服务端返回的功能名称、错误原因和未知动态值。
- 个别单位、时间表达，以及更多终端宽度和字体组合。

静态扫描中的“英文界面候选”只是待复核的位置，可能包含技术词、用户文字、测试外的诊断文本或已经有显示适配器的源文本，不能换算成汉化完成率。命令、配置键、路径、产品名和用户内容按原样保留。

## 测试边界与使用影响

本项目在 Windows x64 上验证，当前预览包仍使用未做发布级性能优化的 `dev-small` 配置。Linux/macOS、完整上游测试集和所有远端功能分支尚未验证。

中文界面与官方入口共享用户账号、配置和会话目录。常规使用时更改设置会保存到共享配置，这是上游行为；本轮只读界面检查前后核对了配置文件哈希。中文版本的启动命令为 `codex-zh`，不会把可执行命令、协议值或用户内容整体翻译成中文。

如果发现回归，可使用上一个发布包恢复 `codex-zh` 入口。请在 Issue 中提供中文修订号、进入页面的命令、终端宽度和复现步骤。
