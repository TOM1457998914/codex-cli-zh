# r7 本地化检查记录

本修订基于固定上游 `rust-v0.169.0`，不更换模型、服务或账号能力。它仍是非官方预览版本。

## 检查方法

- 扫描 Rust 语法树，查找界面文案、帮助属性、动态显示位置和非 Rust 提示资源；逐项区分可翻译文案、技术标识、模型及用户原文。
- 运行完整 TUI 单元测试，以及 CLI、云任务和非交互输出测试。维护中文快照后，必须关闭快照自动更新再运行。
- 对命令分发、配置序列化值、快捷键标识、插件 JSON 策略值及机器诊断数据执行独立检查。
- 使用实际 Windows 终端检查常用界面与命令帮助，验证个人配置没有被测试修改。

静态扫描中的“候选项”并不等于确认漏译，也不能用候选数计算汉化完成率。通过单元测试不能证明所有平台、服务端返回值和运行路径都没有问题。

## 已确认并修复的问题

| 问题 | 原因与处理 |
| --- | --- |
| 状态页缺少推理信息 | 内部查询键被翻译；恢复查询键，只翻译最终显示的名称。 |
| 权限类型显示不准确 | 权限摘要还用于后续分类；保持分类输入与上游一致，在最后的显示函数中翻译。 |
| 代码块或引用复制不完整 | 复制目标的中文名称与英文判断条件不一致；改用共享常量，保留原始 Markdown、空白与换行。 |
| 中文额度名称导致状态栏命令别名失效 | 预览名称识别仍只接受英文；兼容中英文显示名称，序列化标识继续使用原值。 |
| 钩子详情可能崩溃 | 把终端列宽作为 UTF-8 字节偏移；分别计算列宽和字节长度。 |
| 中文 CLI 表格不对齐 | 字节数或字符数无法代表终端列宽；插件与 MCP 表格按显示宽度补空格。 |
| 图片链接点击区域偏移、提及类型占宽过大 | 图片记录和提及标签使用了中文字节数；改按终端显示列宽计算链接与标签。 |
| 语音操作提示位置不稳定 | 用英文长度布局、用中文绘制；测量和绘制使用同一份文案。 |
| 大段粘贴标签发生冲突 | 创建标签与合并草稿时使用不同语言的格式；统一生成方式，并保留已有英文标签的兼容性。 |
| 审批说明中的网址失去链接 | 中文标签直接连接网址，原链接检测无法识别；保留显示分隔空格，网址本身不变。 |
| 空会话导出的判断失效 | 标题已经中文化，空内容判断仍比较英文标题；标题与判断共用常量。 |
| 快捷键文字样式丢失 | 提示识别仍匹配英文后缀；识别中英文提示，按键绑定不变。 |
| 语音失败统计的内部值被翻译 | 统计维度必须保持上游值；恢复机器字段，并用独立检查约束整个统计模块。 |
| 宠物关闭参数和语音关闭原因识别失效 | 恢复 `disable`、`hide`、`off`、`none` 和 `error` 等内部值，审计工具增加对 `matches!` 宏的检查。 |
| 回答界面缺少提交提示 | 快捷键查询的 `submit` / `accept` 标识被翻译；恢复查询标识，新增可见提示断言。 |
| 引导键组合无法保存为有效配置 | 捕获结果必须使用 `leader` 语法；中文仅用于说明，并验证捕获结果可被配置解析器接受。 |
| 搜索记录图标和旁支确认框不完整 | 补齐搜索标签识别与旁支确认说明，确认按钮的点击区域按中文显示宽度计算。 |

## 文案范围

本轮继续覆盖启动引导、警告、登录、模型及服务商选择、权限说明、会话管理、预设、语音、钩子、插件、后台任务、状态与用量、复制与导出，以及 CLI 帮助。

命令名称、参数、配置键、协议字段、遥测维度、工具输出、代码、用户输入和模型回答不做全局替换。未知服务端文案保留原文；这也能避免把服务器错误或用户内容改成不准确的翻译。

## 回归检查重点

中文宽字符在终端占用的列数与 UTF-8 字节数不同。测试辅助代码读取真实可见字符，跳过宽字符的占位单元格，并单独检查链接、光标坐标和文本样式。它不通过删除所有空格来掩盖排版问题。

最终使用上游 `justfile` 同样采用的 Nextest 运行器，让测试在独立进程中运行；关闭失败重试和快照自动更新后再核验。快照只接受经过核对的文字或布局变化，缺少按钮、状态行或不稳定时间的差异需要先修正原因。

侧栏拖动场景还修正了一处测试配置问题：异步重新加载配置会恢复动画，使立即执行的鼠标拖动落在尚未稳定的分隔线上。测试配置现在持久化关闭动画，并明确检查布局已经稳定；原有拖动终点断言保留。此调整只影响测试，不改变正常运行时的动画行为。

复制与粘贴检查包含英文原文、中文、组合字符、emoji、大段粘贴、标签冲突和已有英文标签。测试期生成的账号、聊天及工作目录均用于本地测试，不随项目或安装包分发。

最终数量、哈希、平台与手工检查结果以 [verification.json](verification.json) 为准。
